# トーンとマナーの決め方

エンジンは器です。**面白くするのは、機構をどう使うかの設計**のほうです。
ここには、エッセンスを渡されたときに何を決めるかを書きます。

---

## 1. まず写像を決める（これが全部）

逆転裁判の機構は、そのまま学習の機構に写せます。**先にこの表を埋めてから書き始める。**

| 原作の機構 | プレゼンでの役割 | 埋めるもの |
|---|---|---|
| 証言 | 聴衆がいま持っている**通説・誤解** | 「たぶんこう思っている」を3〜4行 |
| ムジュン | 誤解が事実と衝突する点 = **学びの核** | 今日いちばん持って帰ってほしい1文 |
| 証拠品 | データ・図・引用 = 根拠 | 出典と年つきで4〜6点 |
| つきつける | 聴衆が根拠を選ぶ = **参加** | どの証拠で殴るか |
| ゆさぶる | 深掘り・補足 | 「なんで？」への答え |
| 異議あり！ | 山場 | ここに最重要メッセージを置く |
| 休廷（slide） | 講義パート | 板書したいこと |
| 判決（verdict） | 回収 | 持ち帰り3〜5個 |

**ムジュンが決まらないうちにセリフを書き始めない。** 書き始めると、
ただのキャラ付きスライドになります。

---

## 2. 証言の作り方 — 3手で飛躍させる

いい証言は**正しいことから始まって、最後だけ飛躍する**。

```
1. 正しい（誰も否定できない）      ← ここを潰すと、弁護人が嫌な奴になる
2. 正しい（でも意味が曖昧）        ← 伏線。ゆさぶりで深掘りできる場所
3. 飛躍する                        ← ★ムジュン
4. 飛躍の結論を、行動指針にする    ← ★2つ目のムジュン（あると強い）
```

デモケースの例：

| # | 証言 | 状態 |
|---|---|---|
| 1 | 量子は古典で解けない問題を解く | 正しい |
| 2 | 1,121量子ビットのマシンが動いている | 正しい |
| 3 | だから来年RSAは破られる | **飛躍**（物理と論理の混同） |
| 4 | だから対策は無駄 | **飛躍**（否定と不要の混同） |

**4番目が一番大事です。** 誇大広告を否定した勢いのまま、
「じゃあ何もしなくていい」に乗ってしまう——これが本当に危ない誤解で、
普通のスライドでは指摘しても刺さらない。法廷なら、聴衆が自分で殴れます。

---

## 3. 証拠品の作り方

- **4〜6点。** 3点以下だと当てもの、7点以上だと探すのが作業になる
- **ダミーを混ぜる。** 正解しかないと選ぶ意味がない。正しいが的が外れている証拠を入れる
- **数字には出典と年を書く。** `detail` に書けば、つきつける前に読ませられる
- **証拠は、つきつける前に配る。** `tools/check.mjs` がこれを検査します

---

## 4. 配色プリセット（`meta.theme`）

| 値 | 世界観 | 向いている題材 |
|---|---|---|
| `court` | 濃紺×金。法廷（既定） | 通説を覆す / 技術の誤解を解く |
| `lab` | 青白い。研究室 | 研究報告 / 実験結果 / 検証 |
| `startup` | 黒×蛍光。ピッチ | 事業提案 / 市場の思い込みを壊す |
| `warm` | 茶×琥珀。和やか | ワークショップ / 社内勉強会 |

キャラの色は `cast` で個別に上書きできます（`outfit` / `hairColor` / `tie` / `skin` / `hair`）。

---

## 5. キャラの配役

| 役 | `art` | 役割 |
|---|---|---|
| 裁判長 | `judge` | 認定する人。**学びを言語化して締める** |
| 弁護人 | `hero` | 発表者の分身。聴衆と同じ側 |
| 検事 | `prosecutor` | 反対意見。**強くしておくほど学びが濃くなる** |
| 証人 | `witness` `detective` | 通説を喋る人。悪人にしない |
| 助手 | `assistant` | **聴衆の代弁者**。操作説明もここに言わせる |
| 専門家 | `expert` | 補足の権威 |

**検事を藁人形にしないこと。** 反対側が弱いと、勝っても何も学べません。

**操作説明はキャラに言わせる。** スライドで説明すると空気が止まります。

---

## 6. 尺の目安

| シーン | 目安 |
|---|---|
| 会話 3〜5行 | 30〜60秒 |
| 証言1本（4文＋ゆさぶり＋ムジュン2） | 3〜5分 |
| スライド1枚 | 40〜90秒 |
| 選択肢（挙手つき） | 1〜2分 |

10分なら **証言1本＋スライド2枚＋選択肢1回**。
15分なら **証言2本**。それ以上は入れない。

---

## 7. やりがちな失敗

- **ムジュンを決めずに書き始める** → キャラ付きスライドになる
- **証言が全部おかしい** → どこを突けばいいか分からず、当てものになる
- **証拠が多すぎる** → 探す作業になり、考えなくなる
- **検事が弱い** → 勝っても学びがない
- **端末を見ないと進めない設計** → 当日、発表者は手元を見ません
- **最後に回収しない** → `verdict` の takeaways を必ず書く
